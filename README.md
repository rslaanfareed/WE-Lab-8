# ShopEase Responsive Product Gallery

A responsive e-commerce product gallery created for Web Engineering Laboratory 8.

## Features
- CSS Grid layout using `repeat(auto-fit, minmax(250px, 1fr))`
- Cards automatically adjust to the available screen width.
- No explicit media queries are used for the product grid.
- Product cards include hover lift and shadow animations.
- Separate HTML and CSS files.

## Run locally
1. Download or clone this repository.
2. Keep `index.html` and `style.css` in the same folder.
3. Open `index.html` in a web browser.

## Technologies
- HTML5
- CSS3 (CSS Grid, transitions, gradients)
